# OffTimer_Windows

A tiny Windows shutdown timer built with Python + Tkinter.

## Features
- Add 10 minutes
- Add 1 hour
- Live remaining-time display
- Scheduled shutdown time display
- Cancel shutdown
- Shut down now
- Closing OffTimer normally cancels the scheduled shutdown

## Build on GitHub
No Python, Git, or development tools are required on your PC.

1. Upload these project files to the repository.
2. Create `.github/workflows/build.yml` if the hidden `.github` folder cannot be uploaded through your browser.
3. Open **Actions > Build OffTimer > Run workflow**.
4. After the workflow finishes, download the **OffTimer-Windows-x64** artifact.
5. Extract it and run `OffTimer.exe`.
